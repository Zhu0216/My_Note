# My Note v2 Grill Me Question Queue

These topics were explicitly classified as v2 during the October 2026 v1
completion interview. They are not part of the reopened v1 implementation and
must be resolved through a later Grill Me interview before development.

## Home discovery and scrolling

- Define a Home search icon that performs immediate fuzzy search across the
  local relationship network.
- Decide result grouping, ranking, highlighting, filters, target navigation,
  empty-state wording (`無關連查詢`), and whether hidden or trashed records can
  appear.
- Define sticky Home section headings and the setting that optionally collapses
  a section after its content leaves the viewport.

## General-note Markdown input

- Decide whether Markdown is an input shortcut, a raw-source mode, an import /
  export format, or a fully bidirectional representation of rich text.
- Define precedence and round-trip behavior for toolbar formatting, Markdown
  syntax, images, attachments, todos, and inserted-note blocks.

## Interactive tag editor

- Define space-triggered tag capsules, `#` display/edit behavior, backspace
  re-entry, duplicate handling, pasted text, IME composition, accessibility,
  and existing-tag migration.

## Full document reader

- Define the complete cross-template and document reading experience beyond v1
  lightweight previews.
- Decide PDF text search, navigation, annotations, sharing, recent position,
  supported Office formats, and external-app fallback.

## Structured-template redesign

- Revisit the Plan, Mind Map, and Life Project UI and component choices before
  changing their v1 preview presentations.
- Preserve the approved v1 schemas unless a future migration is separately
  compared and approved.

## Explicit exclusions

- A visual memory-network graph is not a v2 question. It is an intentional
  product non-goal unless the user explicitly reverses that decision.
