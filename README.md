# My Note

My Note 是一款 All-in-one 個人管理筆記本，目標是在手機、平板與網頁上整合筆記、行程、記帳、訂閱與待辦事項。本機功能可離線獨立使用，也可選擇以 Firebase 帳號登入並逐步啟用跨裝置同步。

## 功能

### 首頁 Home

- 顯示今日行程、即將到來、本月收支、最近筆記與待辦事項。
- 提供首頁即時快速查找，可依標題、標籤、內容、關聯資料與附件檔名搜尋所有資料類型；結果依符合程度排序、標示命中文字並可直接開啟來源。
- 今日行程可直接跳轉至行程頁對應日期的當日行程區段。
- 支援首頁區塊排序、顯示 / 隱藏、條列 / 方塊樣式切換與摺疊顯示。
- 下滑首頁時目前區塊標題會固定在內容頂端，方便隨時收合；設定可選擇在區塊完全離開畫面後，僅於本次使用期間自動收合。
- 可見首頁區塊之間以 90% 寬、40% 主題色透明度的細線分隔；隱藏區塊不會留下多餘分隔線。
- 右下角 FAB 可快速新增筆記、待辦、記帳、訂閱費用與行程，展開後點擊頁面空白處可收合。
- FAB 選項以由下往上、由右至左的分段動畫顯示，選項背景、框線與文字會同步移動。

### 導覽與返回

- 四個主功能頁的裝置返回鍵會回到首頁，首頁返回時詢問是否退出；從首頁、資料夾、關聯項目或提醒進入編輯器時，儲存、刪除或返回則回到實際進入來源並保留該頁狀態。
- FAB、側邊欄、篩選、批量模式、Dialog、BottomSheet 與編輯器子工具會優先關閉目前操作，再返回所屬功能頁。
- 筆記編輯器返回時自動儲存並回到實際進入來源；巢狀資料夾本身仍依父路徑逐層返回所有筆記頁。

### 筆記 Notes

- 支援一般筆記、計劃、心智圖、人生試算表等模板入口。
- 支援資料夾、巢狀資料夾、未分類、所有筆記與垃圾桶。
- 一般資料夾只顯示直接隸屬其中的筆記，不會重複顯示子資料夾筆記；所有筆記頁仍顯示全部筆記。
- 支援搜尋、排序、檢視模式、模板篩選、批量編輯、移動、重新命名與刪除。
- 支援資料夾與筆記一起進入批量選取，長按資料夾或筆記可直接進入選取模式。
- 左滑刪除會立即執行並提供 5 秒復原；提示逾時會確實關閉且不回報未執行的復原。連續刪除會先替換舊提示、合併為同一批並重新計時，復原時一併回復原順序、資料夾與關聯。
- 進入資料夾後，上方路徑可點擊切換目錄；路徑中的資料夾名稱過長時以前 5 個字元加省略號顯示。
- 資料夾命名限制為 18 個半形字或 12 個全形字，超過時提示並停用確認，避免輸入欄卡住。
- 支援置頂筆記，置頂筆記會固定顯示在一般筆記上方。
- 垃圾桶提供檢視、復原、刪除與清空功能。

### Rich Note Editor

- 支援文字格式：字級、字型、粗體、斜體、底線、刪除線、上下標、行高、引用、程式碼、編號清單、項目清單與待辦清單。
- 支援 Markdown 即時輸入轉換：粗體、斜體、刪除線、行內程式碼、連結、H1/H2/H3、引用、清單、核取方塊、程式碼區塊與分隔線會直接成為 WYSIWYG 內容；立即復原可還原原始語法。
- 貼上疑似 Markdown 內容時，可選擇保留純文字或轉換為 Rich Text；支援格式可在 Markdown 匯入與匯出間往返，表格語法維持純文字。
- 工具列可切換 Body、H1、H2、H3 段落樣式；標題使用固定字級、粗細與行高，不受一般字級設定覆寫。
- 在段落或清單項目中按 Enter 會建立真正的下一行並把游標留在新行；編號、項目與待辦清單會自動延續，既有下方文字不會搶走游標。
- 在空白段落按 Backspace 合併段落時，游標會留在實際刪除位置；只框選空白行時，工具列不會誤顯示任何文字格式為啟用。
- 字級支援點擊輸入與上下滑動選擇，最小字級為 16；空白提示文字會維持單行並限制顯示尺寸，不影響實際正文與游標字級。
- 行高提供 1、1.25、1.5、1.75、2 五種設定，文字在每行內垂直置中。
- 支援 Samsung 裝置字型偵測，字型選單可顯示 `裝置(目前字體)` 與已安裝裝置字型，例如 `少女體`、`Samsung One`、`Roboto`、`Foundation`。
- 支援插入圖片；選取後可直接拖動、使用八個控制點自由縮放、對齊、鎖定、裁切及刪除。框線預設關閉，啟用後可用 0.1 px 級距滑動或輸入寬度並選擇顏色，粗框線會完整繪製於圖片範圍內並可由子工具列明確關閉。
- 文字與嵌入物件工具列在內容超出寬度時提供固定位置的左右捲動按鈕，抵達邊界後停用按鈕而不改變工具列寬度。
- 支援插入附件、待辦與其他筆記；附件以內容雜湊去重，Android 儲存於 App 私有目錄，Web 儲存於 IndexedDB，並可預覽、交給裝置 App 開啟、另存、重新命名、取代或移除。選取圖片、附件或插入待辦後可用 Delete／Backspace 從筆記移除；待辦只移除引用，不刪除來源資料。插入筆記區塊可預覽摘要、完整編輯、重新指定或移除，並納入關聯索引。
- 筆記文字與編輯區顏色跟隨 App 明暗主題；可選擇封面圖片，封面只在筆記列表以固定高度完整顯示，不佔用內文空間。
- 支援將筆記另存為 PDF、TXT 或 Markdown；PDF 支援繁體中文，Markdown 會保留可對應的 rich text 格式與嵌入內容連結。
- 支援返回自動儲存與刪除確認。
- 新增筆記若內容為空不會建立資料；既有筆記若清空內容會保留原內容，避免誤覆蓋。

### 結構化筆記模板

- 計劃支援階段與任務的巢狀結構、權重進度、優先級、日期及首頁待辦來源。
- 心智圖支援響應式大綱與畫布、節點同步選取、同階層排序、共同形狀、有限色盤、關聯項目、鍵盤操作、縮放置中、交易式連續自由連線、鎖定、收合及一鍵排版；桌面 Ctrl 點擊、框選、行動裝置長按及工具列可啟用多選，並批次拖移、對齊、等距分布、改色、鎖定、設定關聯、刪除與排列。連續自由連線可預覽、返回、取消、整批完成、整批復原／重做，亦支援循環及不同樣式的平行連線。
- 人生試算表支援金錢與狀態／完成率項目、排序、權重及跨資料關聯。
- 人生試算表的金額量表可連結一個或多個帳戶；共用帳戶餘額只計算一次，再依項目順序形成累積門檻。
- 金額門檻會分別顯示目前達成與曾經達成狀態；帳戶餘額下降時保留歷史達成紀錄，同時反映目前進度。

### 行程 Calendar

- 支援月曆、週曆與全部行程清單；月曆與週曆可透過左右箭頭或水平滑動切換期間。
- 月曆日期格會顯示日期與最多三項當日行程，月曆與週曆的選取日期皆使用外框標示。
- 點擊日期後顯示該日行程，新增行程會預設使用目前選取日期與時間。
- 再次點擊目前選取日期會跳轉至當日行程區段，隱藏月曆區塊並保留新增行程按鈕。
- 支援新增、編輯、刪除與提醒設定。
- Google Calendar 同步保留為後續功能。

### 記帳 Finance

- 支援收入、支出、帳戶、分類與時間紀錄；每筆記帳使用穩定帳戶 ID 關聯存餘帳戶。
- 帳戶餘額由「期初餘額 + 收入 - 支出」即時計算，修改或刪除記帳後會立即更新。
- 支援新增、重新命名與調整帳戶期初餘額；仍被記帳使用的帳戶不可直接刪除。
- 支援本月收入、本月支出、存餘金額、支出分類與收入分類統計。
- 支援預算提醒、圓餅 / 環狀圖與日期時間軸紀錄。
- 訂閱管理整合於記帳功能，可記錄訂閱名稱、金額、付款週期、下次付款日、付款方式、分類、提醒天數與啟用狀態。

### 待辦事項

- 支援待辦、完成狀態、期限、提醒與提醒時間。
- 首頁待辦可直接編輯文字，長按可設定期限、提醒、完成或刪除。
- 已完成待辦可集中顯示，並保留完成時間。

### 本機提醒

- Android 會依待辦期限與提醒時間、行程開始前分鐘數、訂閱付款日前天數建立本機通知。
- 新增、修改、完成、停用或刪除來源資料時會以穩定通知 ID 自動重排或取消，不會重複建立同一提醒。
- 提醒使用裝置時區與可在省電待機中執行的非精確排程；重新開機後會由 Android 恢復排程。
- 通知權限會在使用者新增或開啟提醒時要求，也可在設定頁的「本機提醒」手動開啟。
- Android 與 Web 開啟 App 或回到前景時，會顯示尚未看過的到期提醒；點擊提醒可直接開啟來源，同一次提醒不會重複顯示。
- Web Email 與 FCM 屬於後續雲端功能。

### 設定 Settings

- 第一次啟動可選擇登入同步或直接使用本機資料，本機選擇會被記住且不會自動上傳資料。
- 首頁提供精簡帳號入口；設定頁提供 Email/Password 與 Google 登入、電子郵件驗證、密碼重設、credential 連結、登出及帳號刪除。
- 未驗證電子郵件的帳號不可開始同步；Firebase 暫時無法使用時，本機功能仍可正常開啟。
- 首次同步會先比較本機與帳號唯一的雲端資料空間，不會在登入後自動上傳；同 ID 衝突可逐項保留本機、雲端或兩者。
- 雲端內容被不同資料取代前會建立復原版本；設定頁可查看並還原雲端版本，還原前也會保存目前狀態。
- 首次同步完成後採本機優先：每次修改先寫入本機，再由可跨重啟保留的同步佇列傳送；提供 Wi-Fi 自動、任何網路自動與僅手動三種政策，行動網路模式會先提示流量風險。
- 同步狀態包含已同步、等待網路、同步中、衝突與失敗；失敗不會丟棄本機修改，可手動重試，遠端版本變更會下載且不反向製造重複上傳。
- 提供本機通知、資料匯出、匯入與復原備份入口。

## 資料與 Firebase 使用情況

### 目前資料狀態

- 第一版目前以本機資料為主，適合離線開發、功能驗證與裝置測試。
- 本機資料包含筆記、資料夾、行程、待辦、記帳紀錄、訂閱項目、存餘帳戶與首頁顯示設定。
- 本機資料使用 `shared_preferences` 儲存；每次新增、修改、移動、刪除或設定變更都會立即建立版本並依序寫入，避免短時間連續操作造成舊寫入覆蓋新資料。
- 附件內容不寫入 `shared_preferences`：Android 使用 App 私有檔案、Web 使用 IndexedDB，快照只保存 SHA-256 blob ID 與中繼資料；舊 Base64 附件會在驗證寫入成功後原子遷移。
- 單一附件上限為 25 MB；每筆筆記超過 100 MB 後停止接受新附件，附件總量上限為 125 MB。JSON 匯出預設包含附件，也可手動排除檔案內容。
- 儲存層包含主資料、checkpoint、變更 journal、最新備份與多版本備份歷史；啟動時會依版本、時間與資料完整度選擇最新可用狀態。
- 待辦、行程、記帳與訂閱在刪除復原期內保留關聯，逾時後才原子清理失效連結；垃圾桶筆記則到永久刪除時才清理，若 App 在清理前中斷會於下次啟動完成。
- Web 本機開發統一使用 `localhost`，輸入 `127.0.0.1` 或 IPv6 loopback 時會自動導向，避免瀏覽器因不同 origin 建立兩套獨立本機資料。
- 若偵測到舊版範例資料，會避免將其當成使用者資料復原；若主資料損毀，會依序嘗試 checkpoint 與備份歷史，而不以舊範例覆蓋使用者資料。
- 舊版筆記行高會在載入或備份復原時直接轉換為最近的新行高並寫回新資料格式。
- 舊版存餘金額會在載入或匯入時轉換為帳本期初餘額，並將記帳帳戶名稱轉為帳戶 ID；migration 前後的可見帳戶餘額保持一致，舊快照會先進入備份歷史。

### Firebase 使用情況

- Firebase Auth：已啟用 Email/Password 與 Google 登入，並支援驗證、重設、帳號連結、登出與刪除；登入不會自行上傳本機資料。
- Cloud Firestore：正式資料庫位於 `asia-east1` 並啟用刪除保護；首次同步可儲存筆記、資料夾、行程、待辦、訂閱、記帳紀錄、帳戶、預算、首頁設定與可還原雲端版本，安全規則限制每位登入者只能存取自己的路徑。
- Firebase Storage：圖片、封面與附件使用 SHA-256 內容位址去重，下載時驗證完整性；同步程式與測試已完成，目前 Firebase 專案尚未初始化 production Storage bucket，因此正式檔案同步尚未啟用。
- Firebase Cloud Messaging：提供行程提醒、訂閱扣款提醒、待辦提醒與預算提醒推播。
- Cloud Functions：處理背景任務、定期提醒、資料清理與未來 Google Calendar 同步。
- Firebase Hosting：部署 Flutter Web 版本。
